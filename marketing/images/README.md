# first-run screenshots

Place the PNGs listed in the "Screenshots needed" checklist at the top of
`../first-run.md` here, using those exact filenames. `first-run.md` references
them as `./images/<name>.png`.

Capture at 2× (Retina) where possible; crop tight to the dialog or pane in
question, not the whole desktop. Dark UI shots should be the app's own dark
theme.
