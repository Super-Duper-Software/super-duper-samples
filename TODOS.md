- FIXED: when a clip is "selected"/highlighted, you can't scroll below it - the UI starts buggily preventing the user from scrolling further down
  → ResultList re-ran its "scroll selection into view" effect on every scroll frame (`virtualItems` in the deps) and yanked the viewport back. Now it only reacts to the selection actually changing, and focuses the target row once (preventScroll).
- FIXED: waveform scrubbing is wonky (doesn't work if clicking between). also dragging out makes it go crazy
  → The row is `draggable`, so a scrub drag on the waveform started the native OS drag-out: the browser cancelled the pointer stream mid-scrub (click-drag seek did nothing) and began a file drag. Waveform now swallows `dragstart` while it is the active audition row.
- FIXED: search needs to be debounced - it doesn't feel like it currently is. if it is though that's fine
  → It was debounced (250ms in the core) but every keystroke replaced the result list with a full-screen "Searching…", which read as a refetch per key. Now prior results stay on screen while a refined query is in flight; debounce window bumped to 320ms.
- FIXED: FREESOUND_API_KEY is THE SAME as FREESOUND_CLIENT_SECRET - this means that we CANNOT bundle the API key in the app. we either need to limit search to using oauth creds (if possible - check freesounds docs), OR we need to have the worker server be called on every search. prefer the former to keep CF costs down but if it's necessary (as in only API key can run search requests and oauth cannot), that's fine
  → Freesound docs: `/search/text/` (and `/sounds/<id>/`, `/analysis/`, `/similar/`) all accept an OAuth2 Bearer token; only download + write endpoints are "OAuth2 required". So the former works — no per-search Worker call. The app now bundles NO API key: search runs through `authorized()` on the user's bearer token, exactly like download (one refresh + one retry on 401). Worker is still hit only for code exchange + the ~daily refresh.
  → Consequence: no signed-out search. New `<SignInGate/>` replaces the Search view until signed in; `core.search` rejects with `NotSignedInError` when signed out. Library + Collections stay usable offline. ADR-0004 amended; `FREESOUND_API_KEY` removed from config/env/`.env.example`.
  → Still open (unchanged, pre-existing): confirm with Freesound whether the 2000/day limit is per-client_id or per-user-token — now that search spends against it too, per-client_id would sink the design (see ADR-0004 / SETUP.md §2).
- FIXED: scroll does not reset when changing search
  → ResultList now takes a `resetKey` (query + sort + filter); when it changes the list scrolls back to the top and drops the stale selection. Skipped on first mount so the ticket-18 restored selection survives.
